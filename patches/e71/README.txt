Патчи для E71 sw45 (не проверены на телефоне)
=============================================
  library-e71-sw45-extended.vkp  библиотека функций
  bt-pan-mtu_E71v45.vkp          MTU 1500 для Bluetooth
  btnet_E71v45.vkp               врезки для браузера и эльфов

Эльф тот же, что для EL71. Ставить как на EL71: библиотека, MTU, врезки.

find-e71.py, map.tsv - поиск адресов E71 по дампу и результат.
port-mtu-e71.py      - порт MTU-патча с EL71 на E71.
