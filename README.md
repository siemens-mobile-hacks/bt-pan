# BT PAN для BenQ-Siemens EL71 sw45, E71 sw45, Siemens S65 sw58 и SK65 sw50

[English version](README.en.md)

Интернет на телефоне через Bluetooth: ПК (с `nap.sh`) или Android-телефон с включённым
«Bluetooth-модемом» раздаёт интернет, браузер, Java и эльфы ходят в сеть как через GPRS. На E71 не проверялось.

## Что в папке

| Файл | Что это |
|---|---|
| `bt-pan_ELKA.elf` | эльф для EL71 и E71 |
| `bt-pan_SG.elf` | эльф для S65 sw58 и SK65 sw50 |
| `nap.sh` | для ПК |
| `speedtest-pc.py` | сервер спидтеста (`nap.sh` запускает сам, лежать рядом) |
| `patches/` | `patches/el71/` — патчи для EL71, `patches/e71/` — для E71, `patches/s65/` — для S65, `patches/sk65/` — для SK65 |
| `source/` | исходники |
| `phone-manual/` | инструкции со скриншотами: GPRS-профиль, подключение эльфа |

## Патчи (по порядку)

1. `library-...vkp` — библиотека функций. Эльф берёт из неё все функции прошивки (записи 420–471).
   Если стоит старая версия этой библиотеки — откатите её и поставьте новую,
   иначе эльф при запуске напишет, что библиотека не подходит.
2. `bt-pan-mtu...vkp` — обязательно.
3. `btnet_...vkp` — нужен браузеру и эльфам. Без запущенного эльфа ничего не меняет.
   Если эльф пишет «Old hook patch» — откатите `patches/el71/old/...` и поставьте новый.

### S65 sw58 (`patches/s65/`)

1. `library-s65-sw58-extended.vkp` — расширенная библиотека функций с функциями Bluetooth.
2. `bt-pan-mtu_S65v58.vkp` — желательно: без него пакеты не больше 320 байт и на ПК нужен
   `sudo MTU=320 ./nap.sh`.
3. `bt-pan-browser_S65v58.vkp` — нужен только встроенному браузеру без SIM-карты.
   Без запущенного эльфа ничего не меняет.

### SK65 sw50 (`patches/sk65/`)

1. `library-sk65-sw50-extended.vkp` — расширенная библиотека функций с функциями Bluetooth.
2. `bt-pan-mtu_SK65v50.vkp` — желательно: без него пакеты не больше 320 байт и на ПК нужен
   `sudo MTU=320 ./nap.sh`.
3. `bt-pan-browser_SK65v50.vkp` — нужен только встроенному браузеру без SIM-карты.
   Без запущенного эльфа ничего не меняет.

Браузер на S65/SK65: в профиле протокол HTTP, прокси пусто, порт 80, соединение — GPRS-профиль,
домашняя страница с `http://`.

## ПК

1. Сопрягите телефон с ПК.
2. Установите пакеты:
   ```sh
   sudo apt install -y bluez bluez-tools dnsmasq iptables python3
   ```
3. Запустите:
   ```sh
   sudo ./nap.sh        # остановить: ./nap.sh stop
   ```

## Телефон

1. Нужен GPRS-профиль интернета (данные любые). Браузер и Java — на него.
   Как создать: [phone-manual/how-to-setup-gprs.md](phone-manual/how-to-setup-gprs.md).
2. Запустите эльф. В меню «PC» → выбрать ПК → «Connect».
   По шагам со скриншотами: [phone-manual/how-to-setup-elf.md](phone-manual/how-to-setup-elf.md).
3. «Speed test...» — спидтесты, «Ping...» — пинг. Спидтесты работают, только когда телефон подключён к ПК с запущенным `nap.sh`.
4. «Disconnect» — разорвать связь, «Exit» — выйти.

Настройки (ПК и автопереподключение) меняются прямо в эльфе (строки «PC» и «Auto-reconnect»),
или в редакторе BCFG: `zbin\etc\BTPAN.bcfg`.

## Ограничения

- Пока эльф работает, Java по Bluetooth (JSR-82) не работает.
- Пока эльф подключён к ПК, весь интернет телефона (браузер, Java, эльфы) идёт через ПК,
  мобильный интернет (GPRS) не используется.
- Если после «Disconnect» → «Connect» или перезапуска эльфа не работает —
  перезагрузите телефон.
- С SIM-картой не проверялось.

## Сборка

SDK ElfLoader 3: оригинал [siemens-mobile-hacks/sdk](https://github.com/siemens-mobile-hacks/sdk); для сборки нужен изменённый форк [dm468/sdk](https://github.com/dm468/sdk) (добавлены нужные bt-pan прототипы SWI для BT/LMAN/ENIP/сокетов), склонированный в `../sdk` относительно `source/`. Затем:

```sh
cd source && cmake -B build -S . && cmake --build build
```
